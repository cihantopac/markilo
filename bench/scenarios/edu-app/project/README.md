# Quillnest

A writing coach for teenagers.

Quillnest gives short daily writing prompts, reads what students write and answers like a good editor would: one
thing that works, one thing to try next. Streaks are kept private; progress is shown as a growing collection of
finished pieces, not as grades. Teachers can create class spaces and see who is stuck, never a ranking.

## Features

- Daily prompts in five genres (story, opinion, poem, letter, review)
- Editor-style feedback: one strength, one next step
- A private portfolio of finished pieces
- Class spaces for teachers, with no leaderboards
- English and Spanish

## Who it is for

Students aged 13–17 and their teachers.
