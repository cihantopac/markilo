# Kinetra

Physiotherapy between appointments. A licensed physiotherapist sets a programme; Kinetra guides each exercise with
video and the phone's camera, counts repetitions, and shows the therapist how recovery is going. Patients message
their therapist; therapists adjust the programme remotely.

## Features

- Exercise programmes set by licensed physiotherapists
- Camera-guided repetitions with form hints
- Pain and mobility check-ins, shared with the therapist
- Secure messaging; data stored in the EU, GDPR and HIPAA-ready
- English, Dutch and German

## Who it is for

Adults recovering from injury or surgery, and the clinics that treat them.
