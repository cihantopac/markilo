# Pinehold

Shared passwords, API keys and environment variables for small teams, without a security team.

Pinehold keeps a team's secrets end-to-end encrypted, fills them in the browser, injects them into local development
(`pinehold run -- npm start`) and CI, and tells the team when a secret is old, reused or leaked. Onboarding and
offboarding a teammate takes one click.

## Features

- End-to-end encrypted vaults per project, shared by role
- Browser extension that fills passwords and one-time codes
- CLI that injects environment variables into any command and CI job
- Rotation reminders and breach alerts
- Desktop apps for macOS and Windows; works offline

## Who it is for

Agencies, startups and small product teams of 3–50 people.
