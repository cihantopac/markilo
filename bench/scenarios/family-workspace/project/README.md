# Lumenfold

Lumenfold is a privacy-first office suite for small European companies: documents, spreadsheets and e-signatures,
hosted in the EU, end-to-end encrypted.

| Product          | What it does                                              |
| ---------------- | --------------------------------------------------------- |
| Lumenfold Docs   | Collaborative documents with comments and version history |
| Lumenfold Sheets | Spreadsheets with live collaboration and charts           |
| Lumenfold Sign   | Legally binding e-signatures (eIDAS) for contracts        |

The company brand is Lumenfold; each product needs its own icon that clearly belongs to the family.
