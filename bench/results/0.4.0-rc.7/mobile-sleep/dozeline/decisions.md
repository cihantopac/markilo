# Dozeline — design decisions

- 2026-10-30: Mode new. Owner unavailable (benchmark); Markilo chose three directions. step-down: abstract, from the dimming mechanism, no letter/object. heavy-lid: drooping-eyelid gesture (audience world; touches the name's "doze"). lit-arch: initial D turned into a glowing arch (the only letter-led one). Why: category is cool blue/purple with moon/star icons (BetterSleep); a warm dusk palette and non-celestial forms differentiate. Name kept despite the unverified Turkish "doz" (dose) association.
