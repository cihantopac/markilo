# Asset outputs

`markilo export --brand <slug>` writes everything below to `brand/brands/<slug>/exports/`, plus `index.html` (a
preview of every file on the background it is made for — open this first), `README.md` (the files most people need and
what each folder holds) and `asset-manifest.json` (purpose, pixel size, bytes, SHA-256 and source master of every
file). Numbers live in
[`src/export/specs.ts`](../src/export/specs.ts) with their official sources; they were last verified on 2026-10-30.

| Group        | Files                                                                                                                                                                                                                            | Notes and sources                                                                                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `logos`      | primary (horizontal lockup, or the wordmark for wordmark-led kits), secondary (stacked), compact, symbol, wordmark × color / reversed / black / white, SVG + PNG; appmark; overview.png                                          | Reversed variants flip inks to paper and lift low-contrast brand colors to ≥ 3:1 on dark (WCAG 1.4.11). Locked brands export the provided files only.                       |
| `web`        | `favicon.svg` (switches colors under `prefers-color-scheme: dark`), `favicon.ico` (16/32/48), `apple-touch-icon.png` (180, opaque), `icon-192/384/512.png`, `icon-maskable-192/512.png`, `site.webmanifest`, `head-snippet.html` | Maskable content stays inside the 40% radius safe circle; `sizes="any"` only on the SVG link (WHATWG HTML, MDN, web.dev).                                                   |
| `ios`        | `AppIcon.appiconset` with default (opaque), dark (transparent background) and tinted (grayscale) 1024 px images and `Contents.json`; `icon-composer/` background and foreground layers                                           | Apple now recommends Icon Composer `.icon` files; import the layers there. The `appearances` keys in `Contents.json` follow Xcode's output and are not documented by Apple. |
| `macos`      | `AppIcon-1024-square.svg/png` (full-bleed, macOS 26+), `AppIcon-1024-legacy.svg`, `AppIcon.iconset/`, `AppIcon.icns`                                                                                                             | `.icns` uses the classic 824 px rounded body for apps built outside Xcode (Electron, Tauri) and older macOS.                                                                |
| `android`    | `mipmap-{m,h,xh,xxh,xxxh}dpi/` legacy (48–192 px) and round icons, adaptive foreground/background (108 dp × density) and monochrome layers, `mipmap-anydpi-v26/*.xml`, color resource, `play-store-icon-512.png`                 | Foreground content kept inside the 66 dp safe zone; Play icon is a full square (Play applies a 30% radius mask).                                                            |
| `windows`    | `app.ico` (16/24/32/48/64/256), MSIX `Assets/`: Square44x44Logo (scales + 14 target sizes, plated/unplated/light-unplated), Square71/150/310, Wide310x150, StoreLogo, SplashScreen                                               | Microsoft Learn app icon construction.                                                                                                                                      |
| `social`     | `og-image(.svg/.png)` 1200×630 (+ dark), `github-social-preview` 1280×640, `x-header` 1500×500, `linkedin-cover` 1512×256, `avatar-500.png`                                                                                      | X sizes could not be verified against x.com docs (blocked to automated readers).                                                                                            |
| `marketing`  | watermarks (white/black), email signature, title slide template (live text SVG + PNG preview), business card front/back (85 × 55 mm)                                                                                             | Templates keep live text for editing; masters never do.                                                                                                                     |
| `tokens`     | `tokens.json` (W3C Design Tokens format), `tokens.css`, `palette.json` (scales, neutrals, semantic, WCAG pairs, warnings)                                                                                                        | OKLCH tonal scales with the brand color pinned to its nearest step.                                                                                                         |
| `guidelines` | `brand-guidelines.md`, `index.html`                                                                                                                                                                                              | Logo use, clear space, minimum sizes, color with contrast, typography and license, don'ts.                                                                                  |

Copy assets into an app with `markilo install-assets --brand <slug> --group web --into public` (dry run) and add
`--apply` once you have reviewed the plan.
