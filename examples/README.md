# Examples

Briefs are JSON patches for `markilo brief update --brand <slug> --file <patch.json>`. Only fill in what you know;
Markilo's research stage records sources and lists gaps for the rest.

| Folder            | Scenario                                                                                                                  |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `single-product/` | One synthetic product ("Tidepool") from scratch                                                                           |
| `product-family/` | A synthetic multi-product family ("Lumen") with a shared system and a locked member                                       |
| `ovokodo/`        | Starter brief for a real product family (maintainer's own); facts are limited to what was provided and are marked as such |
