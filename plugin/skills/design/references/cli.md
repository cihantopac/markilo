# Markilo CLI reference

`markilo` = `node "${CLAUDE_PLUGIN_ROOT}/dist/markilo.mjs"`. All commands print JSON. Run each command as its own Bash call with the full `node "…/markilo.mjs"` prefix — no shell variables, `cd` or `&&` chains (they defeat the plugin's pre-approved permission). Add `--help` to any
command for its options. `--workspace <dir>` selects a workspace (default: `./brand` or the nearest
`markilo.json` above the current directory).

Quote colours in the shell (`--primary '#1d4e89'`): an unquoted `#` starts a comment and drops the rest of the
command.

## Workspace

| Command                                                                                       | Purpose                                                                                    |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `status`                                                                                      | Workspace (or `found: false`, exit 0), each brand's stage and the next step. Run it first. |
| `init [--name N] [--family F]`                                                                | Create `./brand`. `--family` enables a shared family system.                               |
| `brand add "<Name>" [--role master\|product\|sub-brand\|endorsed] [--parent slug] [--locked]` | Register a brand. `--locked` = preserve exactly, never redesign.                           |
| `brand list`                                                                                  | Brands, concept states, approval/export state.                                             |
| `brief show --brand s` / `brief update --brand s --file patch.json`                           | Read/merge the strategy brief (validated).                                                 |

Brief fields: `oneLiner`, `mode` (new/refresh/redesign/evaluate), `product{type,category,features[],platforms[]}`,
`audience{primary[],secondary[],markets[],languages[]}`, `positioning{values[],personality[],tone,differentiators[]}`,
`competitors[{name,url,notes}]`, `constraints{mustKeep[],avoid[],colors[],typography[]}`, `lockedAssets[]`,
`deliverables[]`, `niceClasses[]`, `notes`.

| `research app "<name\|id\|url>" --brand s --allow-network [--store ios\|android] [--competitor] [--as-reference]`                                                         | App Store (iTunes Search API) / Google Play listing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `research monorepo <repo> [--register --groups products,apps --parent p --lock a,b --scan]`                                                                               | Find sites/apps/packages; register brandable ones with `codePaths`; scan each.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |

| `profile add-source --brand s --type url\|search\|registry\|file\|user --ref R [--notes N]`                                                                               | Log a source with date. | `profile add-finding --brand s --topic T --status observed\|inferred\|verified\|user-provided --statement "…" --source S1,S2 [--confidence low\|medium\|high]`            | Record a finding. observed/verified need sources.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

| `similarity calibrate (--brand s \| <folder>)`                                                                                                                            | Measure how well copies are caught and different marks kept apart on real logos.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `reference add --brand s --file F --name "Brand" --source URL [--category direct\|indirect\|category\|form-family\|inspiration\|dislike\|existing\|family] [--notes "…"]` | Add a reference mark or image. Competitor categories feed similarity and the context sheet; `inspiration`, `dislike` and `existing` are the user's own references (logos, screenshots, mood boards, sketches) — read for characteristics, compared for originality, never shown as competitors. `family` is a mark of the product family this brand joins: `originality` lists it under `family` (family likeness) and leaves it out of the visual risk, the evidence, the name comparison, sketch/variant scoring and the context sheet. |

Topics: product, audience, market, competitor, visual-identity, typography, color, naming, trend, culture, trademark, platform.

| `concept update --brand s --concept ID [--idea "<sentence>" --strengths "a; b" --weaknesses "a; b"] [--wordmark wordmark.svg] [--on-dark\|--on-light <#hex\|none>] [--on-brand <#hex\|auto\|none>] [--tile <#hex\|none>] [--status shortlisted\|rejected] [--judgment memorability=8:"reason"] [--present yes\|no:"reason"] [--blind distinctiveness=n,memorability=n,brand-fit=n,craft=n,versatility=n] [--reviewer <model>] [--reads-as "a; b; c"] [--sketch-pick s3\|none --sketch-notes "…"] [--look <five scores> --look-present yes\|no:"reason"]` | Update files/status/judgment; `--on-dark`/`--on-light` set the brand colour used on that ground in place of `primary`; `--tile` sets the brand tile's ground (app icons, avatars, appmark; default `primary`) and `--on-brand` the one colour the mark takes on it (`auto`: paper or ink, whichever contrasts more; otherwise the mark is adapted automatically); proposals and export use the same colours, locked identities ignore them; `--look` records a fresh critic's second look when the gate says `second-look`. Criteria: brand-fit, semantic-relevance, distinctiveness, memorability, simplicity, balance, craft, typography, color, cultural-fit, timelessness, premium-perception, versatility. Prints the `gate` (blind scores when recorded) with `next` (`present`, `fix`, `present-with-notes`, `second-look`; advice, never reject), the `reviewer` and whether the gate was calibrated on it. Recording scores or an answer stores the drawing they judged (`reviewedArt`); after a redraw the gate is `stale` (old result under `previous`), and `proposals` and `verify` say the critique is older than the drawing. |
| `concept update --brand s --concept ID [--lettering font\|custom\|family] [--supporting-font <id\|none> --supporting-weight <n>]`                                                                                                                                                                                                                                                                                                                                                                                                                        | What the wordmark is: `font` (a typeface set and adjusted, the default), `custom` (lettering drawn for this brand) or `family` (lettering the product family shares). For `custom` and `family`, `proposals` skips `typeset`, and the kit's guidelines and tokens never name the recorded font as the brand typeface ("Wordmark: custom (family) lettering — do not retype it"); `--supporting-font` names the typeface used beside it ("Supporting typeface", token `font.supporting`). A new `--font` keeps both. Bad values return `INVALID_INPUT`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `concept update --brand s --concept ID [--small <file>] [--small-sizes small\|main] [--wordmark-small <file>]`                                                                                                                                                                                                                                                                                                                                                                                                                                           | `--small` registers a simplified symbol that export draws at 32 px and below (`verify` checks it and that it still reads as the main symbol). `--small-sizes main` records the user's choice of the main symbol at every size: export ignores the small version, `proposals` shows the main symbol at 32/16 px, and `verify` turns the main symbol's 16/32 px failures into warnings ending ` — the user chose the main symbol at small sizes.` (`small` restores the default). `--wordmark-small` registers a wordmark drawn for small sizes: exported as `logos/wordmark-small.svg` + `.png` with a guidelines line on when to use it. Bad values return `INVALID_INPUT`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `concept adopt --brand s --concept ID --from OTHER [--files symbol,wordmark,small,lockup]`                                                                                                                                                                                                                                                                                                                                                                                                                                                               | The user chose `ID` but wants to continue from `OTHER`'s drawing: copies those files into `ID` (paths stay inside the concept folders; `lockup` takes both lockups; a wordmark brings its typeface), records `adoptedFrom` on the concept and in `decisions.md`, and re-pins `chosen/` to the adopted drawing, so `chosen-vs-now.png` appears only once it changes and its left panel reads `As the user chose it (from OTHER)`. Refuses an approved concept (`LOCKED`), an unknown `--from` (`NOT_FOUND`) and an unknown file kind (`INVALID_INPUT`). Prints `{ concept, copied, chosen }`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## Verify

| Command                                                                             | Purpose                                                                                                                                              |
| ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `verify --brand s --concept ID`                                                     | All checks; writes reports + `concepts/ID/review/symbol-sheet.png` (and `wordmark-sheet.png`). **Read the PNGs.**                                    |
| `diversity --brand s`                                                               | Pairwise similarity of active concepts.                                                                                                              |
| `originality --brand s --concept ID [--names a,b]`                                  | Originality & Similarity Report only; `family` lists likeness to `family` references, which never count as a risk.                                   |
| `score file.svg [--role symbol\|wordmark\|lockup]` / `analyze file` / `compare a b` | Standalone measurements.                                                                                                                             |
| `svg lint file.svg [--master]`                                                      | Master-file rules.                                                                                                                                   |
| `center in.svg -o out.svg [--force]`                                                | Shift a mark to the optical centre when `balance` says it leans (path data untouched).                                                               |
| `name check "Name" --against a,b,c` / `name trademark "Name" --describe "…"`        | Name confusion and registry pre-screen plan.                                                                                                         |
| `render file.svg -o out.png [--sheet]`                                              | PNG or review contact sheet.                                                                                                                         |
| `render a.svg b.svg… --compare [--paper '#hex'] -o out.png`                         | Sketches side by side on both grounds. With `--sheet` or `--compare`, `--primary '#hex' --on-dark\|--on-light '#hex'` show the chosen ground colour. |
