# Markilo CLI reference

`markilo` = `node "${CLAUDE_PLUGIN_ROOT}/dist/markilo.mjs"`. All commands print JSON. Run each command as its own Bash call with the full `node "…/markilo.mjs"` prefix — no shell variables, `cd` or `&&` chains (they defeat the plugin's pre-approved permission). Add `--help` to any
command for its options. `--workspace <dir>` selects a workspace (default: `./brand` or the nearest
`markilo.json` above the current directory).

Quote colours in the shell (`--primary '#1d4e89'`): an unquoted `#` starts a comment and drops the rest of the
command.

## Workspace

| Command                                                                                                  | Purpose                                                                                                                                                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `status`                                                                                                 | Workspace (or `found: false`, exit 0), each brand's stage and the next step. Run it first.                                                                                                                                                                                                                                                                     |
| `init [--name N] [--family F]`                                                                           | Create `./brand`. `--family` enables a shared family system.                                                                                                                                                                                                                                                                                                   |
| `brand add "<Name>" [--slug s] [--role master\|product\|sub-brand\|endorsed] [--parent slug] [--locked]` | Register a brand. `--locked` = preserve exactly, never redesign. `--slug` sets the folder id. A name with no Latin letters or digits ("日本語") gets `brand-<first 6 hex of sha1(name)>`; the result then has `slugNote` saying so. Such a name cannot be drawn from a bundled font: supply a drawn wordmark SVG (`--wordmark` on `concept update` or `lock`). |
| `brand update --brand s --name "<display name>"`                                                         | Change the display name (slug and folder stay) in the manifest and the brief, and log it in decisions.md. Use it when `research site` returns `suggest: { name }` (the site writes the name differently, e.g. in capitals).                                                                                                                                    |
| `brand list`                                                                                             | Brands, concept states, approval/export state.                                                                                                                                                                                                                                                                                                                 |
| `brief show --brand s` / `brief update --brand s --file patch.json`                                      | Read/merge the strategy brief (validated).                                                                                                                                                                                                                                                                                                                     |

Brief fields: `oneLiner`, `mode` (new/refresh/redesign/evaluate), `product{type,category,features[],platforms[]}`,
`audience{primary[],secondary[],markets[],languages[]}`, `positioning{values[],personality[],tone,differentiators[]}`,
`competitors[{name,url,notes}]`, `constraints{mustKeep[],avoid[],colors[],typography[]}`, `lockedAssets[]`,
`deliverables[]`, `niceClasses[]`, `notes`.

`proposals` (1.6): when `chosen/` holds the drawing the user chose and the symbol or wordmark has changed, the result carries `formChange: { symbol?, wordmark? }` (silhouette IoU 0..1, each drawing fitted to its own ink box at 256 px). Practical notes (1.5). `cost --brand s --plan explore:3,develop:1,critic:1` prints `estimate { agentMinutes, wallMinutes, usd }` and `fits` against the budgets; run it before each round. `render … --width <px>` sets the PNG width for large comparisons. `render a.svg b.svg --compare --tile` adds app-tile renders; pass tiles that way, never as extra options. In shell examples quote answers with single quotes (`$` is expanded inside double quotes). Icon and wordmark go to the user on separate sheets. Masters stay in the primary colour; `verify` warns when a master uses a ground colour (`onLight`/`onDark`).
