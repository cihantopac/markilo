# Markilo CLI reference

`markilo` = `node "${CLAUDE_PLUGIN_ROOT}/dist/markilo.mjs"`. All commands print JSON. Run each command as its own Bash call with the full `node "…/markilo.mjs"` prefix — no shell variables, `cd` or `&&` chains (they defeat the plugin's pre-approved permission). Add `--help` to any
command for its options. `--workspace <dir>` selects a workspace (default: `./brand` or the nearest
`markilo.json` above the current directory).

Quote colours in the shell (`--primary '#1d4e89'`): an unquoted `#` starts a comment and drops the rest of the
command.

## Workspace

| Command                                                                                       | Purpose                                                                                    |
| --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `status`                                                                                      | Workspace (or `found: false`, exit 0), each brand's stage and the next step. Run it first. |
| `init [--name N] [--family F]`                                                                | Create `./brand`. `--family` enables a shared family system.                               |
| `brand add "<Name>" [--role master\|product\|sub-brand\|endorsed] [--parent slug] [--locked]` | Register a brand. `--locked` = preserve exactly, never redesign.                           |
| `brand list`                                                                                  | Brands, concept states, approval/export state.                                             |
| `brief show --brand s` / `brief update --brand s --file patch.json`                           | Read/merge the strategy brief (validated).                                                 |

Brief fields: `oneLiner`, `mode` (new/refresh/redesign/evaluate), `product{type,category,features[],platforms[]}`,
`audience{primary[],secondary[],markets[],languages[]}`, `positioning{values[],personality[],tone,differentiators[]}`,
`competitors[{name,url,notes}]`, `constraints{mustKeep[],avoid[],colors[],typography[]}`, `lockedAssets[]`,
`deliverables[]`, `niceClasses[]`, `notes`.

## Research

| Command                                                                                                                                                           | Purpose                                                                                                                                                                                                                                                                                         |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `research site <url> --brand s --allow-network [--pages 8] [--download-assets] [--allow-private]`                                                                 | Multi-page read: robots, sitemap, brand pages, JSON-LD, colors/fonts, logo candidates; access gaps recorded.                                                                                                                                                                                    |
| `research competitors --brand s --allow-network [--url U --name N]… [--pages 3]`                                                                                  | Competitor findings + logos/icons collected as reference marks.                                                                                                                                                                                                                                 |
| `research app "<name                                                                                                                                              | id                                                                                                                                                                                                                                                                                              | url>" --brand s --allow-network [--store ios\|android] [--competitor] [--as-reference]` | App Store (iTunes Search API) / Google Play listing. |
| `research monorepo <repo> [--register --groups products,apps --parent p --lock a,b --scan]`                                                                       | Find sites/apps/packages; register brandable ones with `codePaths`; scan each.                                                                                                                                                                                                                  |
| `research repo [<path>] --brand s [--full]`                                                                                                                       | Local scan: package.json, README, logos, icon sets, design-system docs, manifests, CSS colors, fonts. Summary by default (full scan cached). Skips secret-like files.                                                                                                                           |
| `profile understanding --brand s`                                                                                                                                 | What the product does, for whom, where and at what price — with sources, stated vs inferred, and what is unknown.                                                                                                                                                                               |
| `profile tidy --brand s`                                                                                                                                          | Rewrite the profile without absolute local paths (before committing a workspace).                                                                                                                                                                                                               |
| `profile show --brand s [--full] [--topic t]`                                                                                                                     | Brand Intelligence Profile summary.                                                                                                                                                                                                                                                             |
| `profile add-source --brand s --type url\|search\|registry\|file\|user --ref R [--notes N]`                                                                       | Log a source with date. Returns its id (S1…).                                                                                                                                                                                                                                                   |
| `profile add-finding --brand s --topic T --status observed\|inferred\|verified\|user-provided --statement "…" --source S1,S2 [--confidence low\|medium\|high]`    | Record a finding. observed/verified need sources.                                                                                                                                                                                                                                               |
| `profile add-gap --brand s --text "…"`                                                                                                                            | Record an unknown.                                                                                                                                                                                                                                                                              |
| `answers --brand s [--question Q --answer A]`                                                                                                                     | Questions already asked; record new ones.                                                                                                                                                                                                                                                       |
| `reference remove --brand s --id ID[,ID]`                                                                                                                         | Remove wrong or duplicate reference marks.                                                                                                                                                                                                                                                      |
| `reference dedupe --brand s [--apply]`                                                                                                                            | Find (and remove) files that add no evidence: near-identical files of one brand, one artwork under two names.                                                                                                                                                                                   |
| `reference list --brand s`                                                                                                                                        | References grouped by brand, with source quality (official, store, catalog, unverified).                                                                                                                                                                                                        |
| `similarity calibrate (--brand s \| <folder>)`                                                                                                                    | Measure how well copies are caught and different marks kept apart on real logos.                                                                                                                                                                                                                |
| `reference add --brand s --file F --name "Brand" --source URL [--category direct\|indirect\|category\|form-family\|inspiration\|dislike\|existing] [--notes "…"]` | Add a reference mark or image. Competitor categories feed similarity and the context sheet; `inspiration`, `dislike` and `existing` are the user's own references (logos, screenshots, mood boards, sketches) — read for characteristics, compared for originality, never shown as competitors. |

Topics: product, audience, market, competitor, visual-identity, typography, color, naming, trend, culture, trademark, platform.

## Design

| Command                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `concept new --brand s --id ID --title T --direction D --rationale R --semantics a,b --primary '#hex' [--secondary --accent --ink --paper] [--font id --weight n] [--lead wordmark] [--round n [--directed "<user's words>"]]`                                                                                                                                                                                                                                | Create `concepts/ID/`. `--round`: the exploration round (at most 3 proposals per round; a round beyond 2 needs the user's direction). Then write `symbol.svg` (the compact icon) and `wordmark.svg`.                                                                                                                                                                                                                                                                     |
| `concept list --brand s`                                                                                                                                                                                                                                                                                                                                                                                                                                      | Concepts with status, files, palette and `gate` (`passed`, `failed`, `not-reviewed`) with the critic average.                                                                                                                                                                                                                                                                                                                                                            |
| `concept show --brand s --concept ID`                                                                                                                                                                                                                                                                                                                                                                                                                         | One concept with its files, palette, typography, critique and `gate`.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `wordmarks --brand s --concept ID [--fonts a,b] [--weights 500,700] [--tracking -20,0,20] \| --pick wN`                                                                                                                                                                                                                                                                                                                                                       | The name in several faces next to the symbol on `review/wordmarks.png`, measured; `--pick` commits one as `wordmark.svg` with its typography.                                                                                                                                                                                                                                                                                                                            |
| `sketches --brand s --concept ID`                                                                                                                                                                                                                                                                                                                                                                                                                             | Optional: build `sketches/*.json` construction specs onto `sketches/board.png` and say which are not `ready` (with `fix` lines). Specs with `members` also get `sketches/family.png`.                                                                                                                                                                                                                                                                                    |
| `construct spec.json -o out.svg [--guides c.png] [--set k=v,…]`                                                                                                                                                                                                                                                                                                                                                                                               | Build a mark from a construction spec (see construction.md).                                                                                                                                                                                                                                                                                                                                                                                                             |
| `construct spec.json --brand s --concept ID [--vary [--max 24]] [--set k=v,…] [--member name] [--role small]`                                                                                                                                                                                                                                                                                                                                                 | Into the concept: `symbol.svg`, `construction.json`, `review/construction.png`; `--vary` ranks variants in `sketches/variants/`.                                                                                                                                                                                                                                                                                                                                         |
| `wordmark --text T --font id --weight n -o out.svg [--tracking=-10] [--case lower] [--color '#hex'] [--locale tr]`                                                                                                                                                                                                                                                                                                                                            | Outlined wordmark with real kerning. Negative tracking needs `=`.                                                                                                                                                                                                                                                                                                                                                                                                        |
| `lockup --symbol a.svg --wordmark b.svg --layout horizontal\|stacked -o out.svg`                                                                                                                                                                                                                                                                                                                                                                              | Cap-height aligned lockup.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ideas --brand s [--add "<hook>" --means "<why>" --source …]`                                                                                                                                                                                                                                                                                                                                                                                                 | Optional idea log (kept for compatibility; the default workflow does not need it).                                                                                                                                                                                                                                                                                                                                                                                       |
| `proposals --brand s [--round n \| --concepts a,b,c]`                                                                                                                                                                                                                                                                                                                                                                                                         | Render a round for the user's decision: `concepts/<id>/review/proposal.png` per concept (the identity on its paper and reversed, the icon as app tile, avatar, 32 and 16 px, the idea) and `proposals/round-<n>.png` side by side; `missing` lists what a proposal still lacks (word, icon, strengths/weaknesses).                                                                                                                                                       |
| `concept update --brand s --concept ID [--idea "<sentence>" --strengths "a; b" --weaknesses "a; b"] [--wordmark wordmark.svg] [--status shortlisted\|rejected] [--judgment memorability=8:"reason"] [--present yes\|no:"reason"] [--blind distinctiveness=n,memorability=n,brand-fit=n,craft=n,versatility=n] [--reviewer <model>] [--reads-as "a; b; c"] [--sketch-pick s3\|none --sketch-notes "…"] [--look <five scores> --look-present yes\|no:"reason"]` | Update files/status/judgment; `--look` records a fresh critic's second look when the gate says `second-look`. Criteria: brand-fit, semantic-relevance, distinctiveness, memorability, simplicity, balance, craft, typography, color, cultural-fit, timelessness, premium-perception, versatility. Prints the `gate` (blind scores when recorded) with `next` (`present`, `fix` once, `reject`, `second-look`), the `reviewer` and whether the gate was calibrated on it. |
| `color compare #a #b [#c…]`                                                                                                                                                                                                                                                                                                                                                                                                                                   | ΔE00 and WCAG contrast between colors (e.g. an accent vs a well-known brand color).                                                                                                                                                                                                                                                                                                                                                                                      |
| `palette '#primary' [--secondary '#…'] [--accent '#…']`                                                                                                                                                                                                                                                                                                                                                                                                       | OKLCH scales, neutrals, semantic colors, WCAG pairs.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `fonts`                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Bundled OFL fonts (inter, manrope, space-grotesk, sora, dm-sans, outfit, plus-jakarta-sans, fraunces, ibm-plex-serif, jetbrains-mono).                                                                                                                                                                                                                                                                                                                                   |

| Command                                                                             | Purpose                                                                                                           |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |

## Deliver

| Command                                                                                                                                           | Purpose                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `finalize --brand s --concept ID --user-choice "<the user's words>" [--tagline T] [--note "usage rule"]... [--accept-risk] [--force]`             | Freeze masters, build lockups (horizontal, stacked, compact) and `brand.json`. Needs the user's choice (a critic's pass alone never finalizes) and an originality verdict of `no-conflicts-found` unless `--accept-risk`.                                                  |
| `lock --brand s --primary '#hex' [--symbol f] [--wordmark f] [--lockup f]`                                                                        | Register an existing identity to preserve byte-for-byte.                                                                                                                                                                                                                   |
| `deliverables --brand s [--set g,…] [--add g,…] [--remove g,…]`                                                                                   | Which groups this brand needs; suggests from product type and platforms.                                                                                                                                                                                                   |
| `export --brand s [--only logos,web,ios,macos,android,windows,social,marketing,tokens,guidelines] [--all] [--clean]`                              | Chosen groups (deliverables) + `asset-manifest.json`.                                                                                                                                                                                                                      |
| `gallery [--brand s] [--serve [--port N]]`                                                                                                        | `brand/gallery/index.html`; `--serve` serves it on 127.0.0.1 (token, read-only, stops when idle) so "Send to your agent" saves decisions.                                                                                                                                  |
| `feedback [--brand s] [--import file] [--apply]`                                                                                                  | Decisions from the gallery: select / change / drop, combine, reject a whole round (with a note), tags, notes, pinned spots, the preferred concept, and ready-to-act `requests`. `--apply` marks selected concepts shortlisted and dropped or round-rejected ones rejected. |
| `cost --brand s [--phase understand\|explore\|refine\|verify\|export (--tokens n \| --usd x) [--minutes m] [--rate r] [--note t]] [--budget usd]` | Cost per creative phase against a budget (default $6). Tokens are estimated at $0.60 per million (measured on Markilo 1.0 runs) unless `--usd` records a measured cost. `status: over` means stop paid work and ask; `warn` at 80 %.                                       |
| `install-assets --brand s --framework auto\|next\|laravel\|flutter\|static [--project <dir>] [--apply [--expect <planId>]] [--force]`             | Files where the framework expects them (plan unless `--apply`; one transaction, replaced files backed up; `--expect` refuses a stale plan). Without `--framework`: `--group web --into public`. `install-assets --undo [--apply]` reverses the last installation.          |
| `agent-setup --target codex\|cursor\|vscode\|generic [--model critic=<id>]... [--apply]`                                                          | The workflow for another coding agent, and the researcher, designer and critic as its sub-agents (`.codex/agents`, `.cursor/agents`, `.github/agents`) on the models named with `--model`. Dry run unless `--apply`.                                                       |
| `shortcut install\|uninstall\|status [--yes]`                                                                                                     | Optional personal `/markilo` skill.                                                                                                                                                                                                                                        |
| `doctor`                                                                                                                                          | Environment check.                                                                                                                                                                                                                                                         |

Error codes: USAGE, NOT_FOUND, EXISTS, UNSAFE_PATH, INVALID_INPUT, INVALID_SVG, NETWORK_DISABLED, NETWORK,
ROBOTS_DISALLOWED, LOCKED, NO_WORKSPACE, INTERNAL.
